## 📐 C · CANON HİZALAMA — sırası gelince

- [ ] **Slogan (sf.3):** "Hayatın Kendi Akışında, Özgürce Hareket." = uydurma varyant. Kilitli sistem: "1998'den beri ustalık…" (ana) / **"Hayat, kendi akışında."** (duygusal/uluslararası) / "Adım adım, birlikte." (kapanış). → Kilitliye dön ya da yeni varyantı Ayhan onaylasın (avukat gate).
- [ ] **Kişilik sıfatları (sf.5):** NET·GÜÇLÜ·ENERJİK·MODERN… → kilitli 4 sıfat (Usta·Çağdaş·İnsan-merkezli·**Dingin**) yok; "Dingin" ↔ "Enerjik/Güçlü" ton çelişkisi. Hizala.
- [ ] **ADALET ikonu (sf.4):** kalkan + medikal artı (+) + kırmızı zemin → hem yasak "medikal artı" hem yasak uyarı-kırmızısı. İkonu değiştir. *(Not: değer ADI kilitli — aşağı bak — sorun yalnız ikon.)*
- [ ] **Gövde tipografisi:** Deck gövdesinde Lora (serif) sızmış (sf.1 alt/3/5/6). Kilitli: **Lora yalnız editorial kapalı liste; gövde = IBM Plex Sans.** Gövdeyi Plex Sans'a çek.
- [ ] **"Rakiplerden ayırır" (sf.4 Cesaret metni):** dışa dönük kullanımda TİTCK kırmızı kuşak (rakip karşılaştırma). İç değer tanımı ama dile sızmasın → yumuşat.

## ➕ D · EKSİK ZORUNLU BÖLÜMLER (brand book tamlığı)

- [ ] **Legal & Usage Rights** (kilitli §4.5) — font lisansları (Plex/Lora OFL), IP sahipliği (sözleşme IP maddesiyle senkron), Talaria tescil/benzerlik taraması, 3. taraf izin. *Şu an tamamen yok.*
- [ ] **Copywriting kuralları** — başlık/CTA/açıklama kalıpları + medikal compliance yeşil/kırmızı kuşak dil listesi
- [ ] **Renk dağılım oranları** — kor aksan ≤%10 doz + WCAG kontrast matrisi (içindekiler vaat ediyor, sayfa yok)
- [ ] **3-yazı-sistemi tipografi** — Arapça companion (Plex Sans Arabic/Amiri) + RTL + Kiril; glyph örnek sayfası
- [ ] **Uygulama/mockup** — kartvizit/tabela/sosyal örnek
- [ ] **Onur & temsil ilkeleri** — görsel dil sayfasına yazılı ilke
